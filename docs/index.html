Features

Everything you actually wanted

Premium-style controls without the premium bill — open source and free forever.

Ad-free streams

Watch without in-stream ads via InnerTube clients — cleaner sessions, fewer interruptions.

YouTube-style mini player

Press Back and keep watching in a bottom bar above navigation. Tap to expand anytime.

Picture-in-Picture

System PiP while a video is playing — multitask without losing your place.

Background play

Screen-off audio with MediaSession: lock screen, notification shade, and Bluetooth controls.

SponsorBlock

Auto-skip sponsors, intros, outros and more — categories you can toggle in Settings.

Return YouTube Dislike

See community dislike counts again when the API has data for a video.

Live and Shorts

Live HLS playback and a dedicated Shorts shelf with badges and vertical-friendly player.

Speed and player tools

0.25×–3× speed, mute, loop, ±10s, next, like, save, share, download, audio-only mode.

Dark and light themes

Full Material themes that follow your preference — not a half-broken toggle.

FAQ

Questions, answered

Is VibeTube free?

Yes. The app is free and open source under the GNU GPL v3.0. Download APKs from the official GitHub Releases page.

Is this affiliated with YouTube or Google?

No. VibeTube is an unofficial third-party client. “YouTube” is a trademark of Google LLC. Use the app responsibly and in line with applicable terms and laws.

Background play doesn’t work — what should I try?

Enable Background play in Settings, start a video, then lock the phone. Allow notifications if Android asks. Some OEMs aggressively kill background apps — exclude VibeTube from battery optimizations.

Where do I report bugs?

Open an issue on GitHub Issues. For security-sensitive reports, see SECURITY.md in the repo.

Can I build it myself?

Yes — clone the repo, run flutter pub get and flutter build apk --release. See docs/BUILD.md for signing notes.
